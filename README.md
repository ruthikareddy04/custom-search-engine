# 🔍 Custom Search Engine

A Django-based Custom Search Engine that crawls websites, indexes web pages, and provides keyword-based search using the TF-IDF algorithm.

## Features

- Website crawling
- Search indexing
- TF-IDF relevance ranking
- Search history
- Analytics dashboard
- Responsive interface

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- BeautifulSoup
- Requests

## Installation

1. Clone the repository

```bash
git clone https://github.com/ruthikareddy04/custom-search-engine.git
```

2. Create a virtual environment

```bash
python -m venv env
```

3. Activate the environment

```bash
env\Scripts\activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

5. Run migrations

```bash
python manage.py migrate
```

6. Start the server

```bash
python manage.py runserver
```

7. Open in your browser

```
http://127.0.0.1:8000/
```
